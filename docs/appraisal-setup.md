# ระบบประเมินผลบุคลากร — คู่มือติดตั้งและใช้งาน

แปลงจากไฟล์ต้นแบบ (HTML เดี่ยว เก็บข้อมูลในเครื่อง) มาเป็นส่วนหนึ่งของ Prime Power Intranet

## สิ่งที่เปลี่ยนจากต้นแบบ

| ต้นแบบ | ในระบบ intranet |
|---|---|
| เลือกชื่อผู้ใช้จาก dropdown เพื่อเข้าระบบ | ใช้บัญชี Microsoft 365 ที่ล็อกอินอยู่แล้ว |
| กำหนดบทบาท EMPLOYEE / SUPERVISOR / HEAD / HR_ADMIN เอง | ระบบดูจากข้อมูลจริง (ดูหัวข้อ "สิทธิ์") |
| ข้อมูลอยู่ใน localStorage (หายเมื่อล้างเบราว์เซอร์) | เก็บใน SharePoint ใช้ร่วมกันทั้งองค์กร |
| หัวข้อประเมินฝังในโค้ด | แก้ได้เองที่ จัดการข้อมูล → หัวข้อประเมิน |
| Audit Log แยกหน้า | บันทึกประวัติไว้ในใบประเมินแต่ละใบ + SharePoint เก็บเวอร์ชันย้อนหลังให้อยู่แล้ว |

## สิทธิ์

| บทบาท | ดูจาก | ทำอะไรได้ |
|---|---|---|
| พนักงาน | ทุกคน | ประเมินตนเอง ลงนามรับทราบผล |
| ผู้ประเมิน | ช่อง Manager ในทะเบียนบุคลากร | ให้คะแนน สรุปผล ลงนาม |
| ผู้บริหาร | ช่องระดับ (Level) เป็นผู้จัดการฝ่ายขึ้นไป | อนุมัติผล ปรับคะแนนสรุป |
| **ฝ่ายบุคคล** | Settings → **HR** (อีเมลคั่นด้วยจุลภาค) | สร้างแบบประเมิน กรอกวันลา ตรวจสอบและลงนาม แก้ผลสรุป ดูภาพรวมทั้งองค์กร · ในหน้าจัดการข้อมูลเห็นเฉพาะ 3 ชุดของระบบประเมิน |
| ผู้ดูแลระบบ | Settings → **Admins** | ทำได้ทุกอย่างของฝ่ายบุคคล และแก้ข้อมูลทุกชุด |

> สิทธิ์ในเว็บเป็นแค่การซ่อนหน้าจอ สิทธิ์จริงอยู่ที่ SharePoint
> คนในรายชื่อ HR ต้องมีสิทธิ์ **Edit** ใน List AppraisalCycles, AppraisalCriteria และ Appraisals ด้วย จึงจะบันทึกได้

## หมวดหมู่ในเว็บ

- **เมนูหลัก → ประเมินผลบุคลากร** (ทุกคนเห็น) แสดงแท็บตามสิทธิ์
  1. **การประเมินของฉัน** — กรอกแบบประเมินตนเอง ดูคะแนน และลงนามรับทราบ
  2. **ทีมของฉัน** — เห็นเฉพาะคนที่ระบุว่าเราเป็นผู้บังคับบัญชา
  3. **อนุมัติผล** — ผู้จัดการฝ่ายขึ้นไป หรือผู้ดูแลระบบ
  4. **ภาพรวมทั้งองค์กร** — ฝ่ายบุคคลและผู้ดูแล ดูความคืบหน้ารายฝ่าย สร้างใบที่ยังขาด ส่งออก CSV
- **จัดการข้อมูล** มี 3 ชุด: **สร้างแบบประเมิน · หัวข้อประเมิน · ใบประเมินรายบุคคล** (ชุดสุดท้ายดูอย่างเดียว)

## SharePoint List ที่ต้องสร้าง

ทุกคอลัมน์แบบหลายบรรทัดต้องเป็น **Plain text** เท่านั้น ถ้าเป็น Rich text ระบบจะอ่าน JSON กลับมาไม่ได้

### 1. AppraisalCycles (สร้างแบบประเมิน)
| คอลัมน์ | ชนิด | หมายเหตุ |
|---|---|---|
| Title | Single line of text | ชื่อแบบประเมิน เช่น ทดลองงาน รอบที่ 1/2569 |
| FormSet | Single line of text | ชุดแบบประเมินที่ใช้ |
| Round | Single line of text | ครั้งที่ 1–4 หรือค่าที่กำหนดเอง เช่น รอบเดือนมกราคม 2570 · ถ้าเป็น Choice ต้องเปิด "Can add values manually" |
| RoundDate | Date | วันที่ประเมินครั้งนี้ |
| Status | Single line of text | `เปิด` / `ปิด` |
| Stage | Single line of text | ประเมินตนเอง / หัวหน้าประเมิน / ผู้บริหารอนุมัติ / พนักงานรับทราบ |
| Scope | Single line of text | `บุคลากรทุกคน` / `เฉพาะรายชื่อที่ระบุ` |
| Members | Multiple lines of text (Plain) | อีเมลผู้ถูกประเมิน บรรทัดละคน |
| StartDate, EndDate | Date | |
| SortOrder | Number | |
| IsActive | Yes/No | |

### 2. AppraisalCriteria (หัวข้อประเมิน)
| คอลัมน์ | ชนิด |
|---|---|
| Title | Single line of text (ชื่อหัวข้อ) |
| FormSet | Single line of text (ชุดแบบประเมินที่หัวข้อนี้อยู่) |
| Section | Single line of text (หมวด) |
| Weight | Number (น้ำหนักข้อ %) |
| SectionWeight | Number (น้ำหนักหมวด % ใส่แถวแรกของหมวดพอ) |
| Scale | Number (5 หรือ 10) · SortOrder | Number · IsActive | Yes/No |

แบบผ่านงาน (FM-HRM-004) มีหัวข้อมาตรฐานติดมากับระบบแล้ว ไม่ต้องเพิ่ม ถ้าเพิ่มหัวข้อที่ FormSet ตรงกัน ระบบจะใช้หัวข้อที่เพิ่มแทน

### 3. Appraisals (ใบประเมินรายบุคคล)
| คอลัมน์ | ชนิด |
|---|---|
| Title | Single line of text |
| CycleName, FormSet, EmployeeName, EmployeeEmail, Department, Section | Single line of text |
| EvaluatorName, EvaluatorEmail, Status, Grade | Single line of text |
| SelfScore, MgrScore, FinalScore | Number (ทศนิยม 2 ตำแหน่ง) |
| SelfComment, MgrComment, HeadComment | Multiple lines of text (Plain) |
| SelfData, MgrData, Log, Extra | Multiple lines of text (Plain) — เก็บ JSON |
| AckDate | Date |

`Extra` เก็บข้อมูลที่ฝ่ายบุคคลกรอก: วันเริ่มงาน วันประเมินแต่ละครั้ง วันขาด ลา มาสาย ผลสรุป และลายเซ็น

## ขั้นตอนเปิดใช้งาน

1. สร้าง 3 List ข้างบน แล้วคัดลอก GUID ไปใส่ใน `scripts/core/config.js` ที่ `appraisalCycles`, `appraisalCriteria`, `appraisals`
2. ใส่อีเมลฝ่ายบุคคลใน Settings → รายการ **HR** และให้สิทธิ์ Edit ใน 3 List นี้
3. (เฉพาะ KPI หรือแบบอื่น) จัดการข้อมูล → **หัวข้อประเมิน** ใส่หัวข้อและน้ำหนัก รวมทุกข้อควรได้ 100%
4. จัดการข้อมูล → **สร้างแบบประเมิน** → **+ เพิ่มรายการ**
   - ตั้งสถานะ `เปิด` และขั้นตอน `ประเมินตนเอง`
   - เลือก "ประเมินครั้งที่" และ "วันที่ประเมินครั้งนี้" (หรือ **อื่นๆ / กำหนดเอง** สำหรับ KPI)
   - เลือกผู้ถูกประเมิน แล้วกรอกตารางด้านล่างได้ทันที
     - **ส่วนที่ 1 : ข้อมูลการทดลองงาน** (เฉพาะแบบผ่านงาน) วันเริ่มงานและวันประเมินแต่ละครั้ง ฝ่ายบุคคลกำหนดเอง ช่องของครั้งนี้ใช้ "วันที่ประเมินครั้งนี้" ให้อัตโนมัติ
     - **ส่วนที่ 2 : บันทึกการมาปฏิบัติงาน** มาสาย ขาดงาน ลากิจ ลาป่วย ลาอื่นๆ
   - กด **สร้างแบบประเมิน** ระบบสร้างใบให้ทุกคนในรายชื่อ (เฉพาะแบบที่สถานะเปิด) และใส่ข้อมูลในตารางลงแต่ละใบ ถ้าสร้างใบไหนไม่สำเร็จจะแจ้งชื่อให้
5. แก้ข้อมูลภายหลังได้ที่ปุ่ม **✎ แก้ไข** ของแบบประเมินเดิม เพิ่มรายชื่อได้ ระบบสร้างใบให้เฉพาะคนที่ยังไม่มี
6. เปลี่ยน **ขั้นตอนที่เปิด** เป็น `หัวหน้าประเมิน` เมื่อพนักงานกรอกครบ ขั้นหลังจากนั้นเดินตามสถานะของใบแต่ละคน

> พนักงานที่อยู่ในรายชื่อแต่ยังไม่มีใบ ระบบจะสร้างใบของคนนั้นให้เองตอนเขาเปิดหน้าประเมิน
> ระบบไม่สร้างใบให้ทุกคนเมื่อผู้ดูแลเปิดหน้าอีกแล้ว ถ้าเพิ่งเพิ่มพนักงานใหม่ ให้กด **↻ ตรวจและสร้างใบที่ยังขาด** ในแท็บภาพรวม

## ลำดับขั้นของใบประเมิน

ประเมินตนเอง → **ผู้ประเมินให้คะแนน สรุปผล และลงนาม** → **ฝ่ายบุคคลตรวจสอบและลงนาม**
→ ผู้บริหารอนุมัติและลงนาม → พนักงานลงนามรับทราบ → เสร็จสมบูรณ์

- ฝ่ายบุคคลส่งตรงให้พนักงานรับทราบได้ โดยข้ามขั้นผู้บริหาร (ปุ่มในใบประเมิน)
- **ผลสรุป** (บรรจุ / ทดลองงานต่อ / ไม่ผ่าน / อื่นๆ) มีชุดเดียว ผู้ประเมินกรอกในขั้นของตน ฝ่ายบุคคลแก้ได้ทุกขั้นด้วยปุ่ม **บันทึกผลสรุป (HR)**
- ผู้ประเมินเห็นวันเริ่มงาน วันประเมินแต่ละครั้ง และวันลา เป็นแถบด้านบนของใบ (ดูอย่างเดียว)
- ทุกขั้นมีช่องลายเซ็น วาดด้วยเมาส์/นิ้ว หรืออัปโหลดรูปก็ได้ เก็บไฟล์ในคลังเอกสารของไซต์
- ทุกขั้นบันทึกชื่อผู้ทำและวันเวลา แสดงเป็นแถบสถานะในใบประเมิน
- ปุ่มส่งออกเอกสารใช้ได้ทุกขั้น สำหรับพิมพ์ให้เซ็นบนกระดาษ (FM-HRM-004)
- ขั้นตอนที่ตั้งในแบบประเมินคุมเฉพาะ 2 ขั้นแรก ขั้นที่เหลือเดินตามสถานะของใบแต่ละคน

## การให้คะแนน

- แบบทั่วไป: ข้อละ **1–5** แปลงเป็น 100 คะแนนตามน้ำหนักข้อ · เกรด A ≥ 90 · B+ ≥ 80 · B ≥ 70 · C ≥ 60 · ต่ำกว่านั้น D
- แบบผ่านงาน (FM-HRM-004): ข้อละ **1–10** · เกรด A 91–100 / B+ 86–90 / B 81–85 / C 70–80 / F ต่ำกว่า 70
- ผู้บริหารปรับคะแนนสรุปได้ตอนอนุมัติ (Calibration) และส่งกลับให้แก้ไขได้

## ข้อจำกัดที่ยังมี

- เปิดใช้แบบประเมินได้ทีละ 1 แบบ ระบบหยิบแบบแรกที่สถานะเปิด
- ข้อมูลใบประเมินอยู่ใน List เดียว ใครมีสิทธิ์อ่าน List นี้ใน SharePoint จะเห็นคะแนนของทุกคน
- ยังไม่มี: มอบหมายผู้ประเมินแทน (Delegate), ปลดล็อกใบรายคน, ขยายเวลาเฉพาะราย

## ทดสอบโดยไม่ต่อ SharePoint

ตั้ง `dataSource: 'mock'` ใน `scripts/core/config.js` แล้วเปิดผ่านเซิร์ฟเวอร์ในเครื่อง
`data/mock/appraisal*.json` มีแบบประเมินทดลองงานตัวอย่าง 1 แบบ กับใบประเมิน 2 ใบ (ขั้นประเมินตนเอง และขั้นหัวหน้าประเมิน)
อย่าลืมสลับกลับเป็น `'sharepoint'` ก่อนอัปขึ้นเซิร์ฟเวอร์
