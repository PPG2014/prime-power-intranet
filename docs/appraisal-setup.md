# ระบบประเมินผลบุคลากร — คู่มือติดตั้ง

แปลงจากไฟล์ต้นแบบ (HTML เดี่ยว เก็บข้อมูลในเครื่อง) มาเป็นส่วนหนึ่งของ Prime Power Intranet

## สิ่งที่เปลี่ยนจากต้นแบบ

| ต้นแบบ | ในระบบ intranet |
|---|---|
| เลือกชื่อผู้ใช้จาก dropdown เพื่อเข้าระบบ | ใช้บัญชี Microsoft 365 ที่ล็อกอินอยู่แล้ว |
| กำหนดบทบาท EMPLOYEE / SUPERVISOR / HEAD / HR_ADMIN เอง | ระบบดูจากข้อมูลจริง: ผู้บังคับบัญชาจากทะเบียนบุคลากร · ผู้บริหารดูจากช่องระดับในผังฝ่าย · ฝ่ายบุคคลคือรายชื่อใน Settings → Admins |
| ข้อมูลอยู่ใน localStorage (หายเมื่อล้างเบราว์เซอร์) | เก็บใน SharePoint ใช้ร่วมกันทั้งองค์กร |
| หัวข้อประเมินฝังในโค้ด | แก้ได้เองที่ จัดการข้อมูล → หัวข้อประเมิน |
| Audit Log แยกหน้า | บันทึกประวัติไว้ในใบประเมินแต่ละใบ + SharePoint เก็บเวอร์ชันย้อนหลังให้อยู่แล้ว |

## หมวดหมู่ในเว็บ

- **เมนูหลัก → ประเมินผลบุคลากร** (ทุกคนเห็น) มี 4 แท็บ แสดงตามสิทธิ์จริงของแต่ละคน
  1. **การประเมินของฉัน** — กรอกแบบประเมินตนเอง ดูคะแนน และกดรับทราบผล
  2. **ทีมของฉัน** — เห็นเฉพาะคนที่ระบุว่าเราเป็นผู้บังคับบัญชา
  3. **อนุมัติผล** — ผู้จัดการฝ่ายขึ้นไป หรือผู้ดูแลระบบ ปรับคะแนนสรุปและอนุมัติได้
  4. **ภาพรวมทั้งองค์กร** — ผู้ดูแลระบบ ดูความคืบหน้ารายฝ่าย สร้างใบประเมิน และส่งออก CSV
- **จัดการข้อมูล** เพิ่ม 3 ชุด: **รอบประเมินผล · หัวข้อประเมิน · ใบประเมินรายบุคคล** (ชุดสุดท้ายดูอย่างเดียว)

## SharePoint List ที่ต้องสร้าง

### 1. AppraisalCycles (รอบประเมิน)
| คอลัมน์ | ชนิด |
|---|---|
| Title | Single line of text (ชื่อรอบ) |
| Status | Single line of text (`เปิด` / `ปิด`) |
| Stage | Single line of text (ประเมินตนเอง / หัวหน้าประเมิน / ผู้บริหารอนุมัติ / พนักงานรับทราบ) |
| StartDate, EndDate | Date |
| SortOrder | Number · IsActive | Yes/No |

### 2. AppraisalCriteria (หัวข้อประเมิน)
| คอลัมน์ | ชนิด |
|---|---|
| Title | Single line of text (ชื่อหัวข้อ) |
| Section | Single line of text (หมวด) |
| Weight | Number (น้ำหนักข้อ %) |
| SectionWeight | Number (น้ำหนักหมวด % ใส่แถวแรกของหมวดพอ) |
| Scale | Number (5 หรือ 10) · SortOrder | Number · IsActive | Yes/No |

### 3. Appraisals (ใบประเมินรายบุคคล)
| คอลัมน์ | ชนิด |
|---|---|
| Title | Single line of text |
| CycleName, EmployeeName, EmployeeEmail, Department, Section | Single line of text |
| EvaluatorName, EvaluatorEmail, Status, Grade | Single line of text |
| SelfScore, MgrScore, FinalScore | Number (ทศนิยม 2 ตำแหน่ง) |
| SelfComment, MgrComment, HeadComment | Multiple lines of text (**Plain text**) |
| SelfData, MgrData, Log, **Extra** | Multiple lines of text (**Plain text**) — เก็บ JSON |
| **FormSet** | Single line of text (ชุดแบบประเมินที่ใช้) |
| AckDate | Date |

> ทุกคอลัมน์แบบหลายบรรทัดต้องเป็น **Plain text** เท่านั้น ถ้าเป็น Rich text ระบบจะอ่านคะแนนกลับมาไม่ได้

## ขั้นตอนเปิดใช้งาน

1. สร้าง 3 ลิสต์ข้างบนใน SharePoint
2. คัดลอก GUID ของแต่ละลิสต์ไปใส่ใน `scripts/core/config.js` ที่ `appraisalCycles`, `appraisalCriteria`, `appraisals`
3. จัดการข้อมูล → **หัวข้อประเมิน** ใส่หัวข้อและน้ำหนัก (รวมทุกข้อควรได้ 100%)
4. จัดการข้อมูล → **รอบประเมินผล** สร้างรอบใหม่ ตั้งสถานะ `เปิด` และขั้นตอนเป็น `ประเมินตนเอง`
5. หน้าประเมินผลบุคลากร → แท็บ **ภาพรวมทั้งองค์กร** → กด **สร้างใบประเมินให้ผู้ที่ยังไม่มี**
6. เมื่อพนักงานกรอกครบ ฝ่ายบุคคลเปลี่ยน **ขั้นตอนที่เปิด** เป็น `หัวหน้าประเมิน` → `ผู้บริหารอนุมัติ` → `พนักงานรับทราบ` ตามลำดับ

## การให้คะแนน

- ให้คะแนนข้อละ **1–5** ระบบแปลงเป็น 100 คะแนนตามน้ำหนักข้อ (5 ทุกข้อ = 100, 3 ทุกข้อ = 60)
- เกรด: A ≥ 90 · B+ ≥ 80 · B ≥ 70 · C ≥ 60 · ต่ำกว่านั้น D
- ผู้บริหารปรับคะแนนสรุปได้ตอนอนุมัติ (Calibration) และส่งกลับให้แก้ไขได้

## ส่วนที่ยังไม่ได้ทำจากต้นแบบ

- มอบหมายผู้ประเมินแทน (Delegate) — ปัจจุบันใช้ผู้บังคับบัญชาจากทะเบียนบุคลากรเท่านั้น
- ล็อกรายขั้นตอนแยกจากรอบ (Master Switch) — ใช้การตั้ง "ขั้นตอนที่เปิด" และสถานะรอบแทน
- ปลดล็อกรายบุคคล (unlock) และการขยายเวลาเฉพาะราย


## แบบประเมินทดลองงาน (FM-HRM-004)

- ตั้ง **ชุดแบบประเมิน** เป็นชุดที่มีคำว่า "ทดลองงาน" หรือ "ผ่านงาน" ระบบจะสลับเป็นโหมดทดลองงานให้เอง
  (สเกล 1–10 · เกณฑ์เกรด A 91-100 / B+ 86-90 / B 81-85 / C 70-80 / F <70 · มีส่วนที่ 1, 3, 4 · ส่งออกเอกสารตามฟอร์ม)
- เพิ่มคอลัมน์ **StartDate** (Date) ในทะเบียนบุคลากร สำหรับคำนวณกำหนดประเมิน 30 / 60 / 90 / 120 วัน
- ตั้งรอบเป็น **เฉพาะรายชื่อที่ระบุ** แล้วใส่รายชื่อพนักงานใหม่ในรอบนั้น
