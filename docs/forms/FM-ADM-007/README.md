# FM-ADM-007 แบบฟอร์มแจ้งซ่อม — ไฟล์นำเข้า

นำเข้าตามลำดับที่ เว็บ → จัดการข้อมูล → (ชุดข้อมูล) → **+ เพิ่มรายการ** → **⬆ นำเข้าจากไฟล์ CSV**

1. `1-FormCatalog.csv` → ชุด **แบบฟอร์ม**
2. `2-FormFields.csv` → ชุด **ช่องกรอกของแบบฟอร์ม**
3. `3-ApprovalMatrix.csv` → ชุด **เส้นทางอนุมัติ**

ก่อนนำเข้าข้อ 3 ต้องมีคอลัมน์ `ConditionField` และ `ConditionValues` (Single line of text) ใน List **ApprovalMatrix**

| ประเภทงานซ่อม (`repair_type`) | ส่งไปที่ |
|---|---|
| คอมพิวเตอร์/อุปกรณ์ IT | ทุกคนใน ฝ่ายประสานงานและอำนวยการ |
| อุปกรณ์ เครื่องมือวัด/เครื่องมือช่าง | ทุกคนใน ฝ่ายจัดซื้อและคลังสินค้า |
| อาคาร-สถานที่ | ทุกคนใน ฝ่ายควบคุมการเดินระบบและบำรุงรักษา |
| อื่นๆ | ทุกคนใน ฝ่ายประสานงานและอำนวยการ |

หลังฝ่ายที่รับเรื่องอนุมัติแล้ว ทุกประเภทงานซ่อมจะส่งให้ผู้บริหารลงนามต่อตามลำดับ (มีช่องลงนามในเอกสารที่ส่งออก/พิมพ์):

| ลำดับ | ผู้ลงนาม |
|---|---|
| 5 | กานต์ธิดา ใสสะอาด — รองกรรมการผู้จัดการด้านการเงิน |
| 6 | ไพรัช เขียนเขว้า — กรรมการผู้จัดการ |

**ถ้านำเข้าลำดับ 1–4 ไปแล้ว** ให้นำเข้า `3b-ApprovalMatrix-exec-sign.csv` (เฉพาะลำดับ 5–6) เข้าชุด **เส้นทางอนุมัติ** เพิ่มอย่างเดียว ไม่ต้องนำเข้าไฟล์ 3 ซ้ำ
(ชื่อผู้ลงนามอยู่ในคอลัมน์ `ExtraApprovers` ต้องสะกดตรงกับทะเบียนบุคลากร · เปิดหน้าแก้ไขแบบฟอร์มแล้วกดบันทึกหนึ่งครั้ง ระบบจะย้ายชื่อไปไว้ในช่องผู้อนุมัติให้)

อยากส่งให้บุคคลแทนทั้งฝ่าย: จัดการข้อมูล → แบบฟอร์ม → ✎ แก้ไข FM-ADM-007 → ขั้นที่ต้องการ → ประเภท **ระบุชื่อเจาะจง** แล้วเลือกชื่อ (เงื่อนไขเดิมคงอยู่)
