# FM-SMD-001 แบบฟอร์มใบจองและสั่งซื้อระบบโซลาร์เซลล์ — ตั้งค่าครั้งแรก

ฟอร์มนี้มี **หน้ากรอกเฉพาะ** (คำนวณราคา · ลายเซ็น 3 ช่อง · Solar Calculator · ส่งออกเอกสาร 2 แบบ)
ช่องกรอกกำหนดในโค้ดแล้ว **ไม่ต้องนำเข้า FormFields**

## 1. เพิ่มแบบฟอร์ม
จัดการข้อมูล → **แบบฟอร์ม** → ⬆ นำเข้าจากไฟล์ CSV → `1-FormCatalog.csv`
(ต้องมีฝ่าย "ฝ่ายขายและการตลาด" ในทะเบียนหน่วยงาน)

## 2. เส้นทางอนุมัติ (ปรับได้)
จัดการข้อมูล → **เส้นทางอนุมัติ** → นำเข้า `3-ApprovalMatrix.csv`
ตัวอย่างตั้งไว้ 1 ลำดับ: ผู้จัดการฝ่ายขายและการตลาด ตรวจสอบใบจอง — แก้ได้ที่ แบบฟอร์ม → ✎ แก้ไข FM-SMD-001
(ไม่ตั้งเส้นทาง: ใบจองยังบันทึกได้ แต่ขึ้นเตือนว่าไม่มีผู้อนุมัติ)

## 3. ราคา (Price List) — ข้อมูลลับ ห้ามใส่ใน GitHub
เว็บนี้เปิดสาธารณะ ราคาจึงเก็บใน SharePoint (ตั้งค่าระบบ `SolarPriceList`) ไม่อยู่ในโค้ดหรือไฟล์ใน repo

จัดการข้อมูล → **💲 ราคาโซลาร์เซลล์** → **⬆ นำเข้า JSON** (ไฟล์ `solar-price-list.json` ที่ได้รับแยกต่างหาก) → ตรวจตัวเลข → **💾 บันทึก**
หรือกรอกในตาราง: A ระบบ 1 เฟส / 3 เฟส · B แบตเตอรี่ · C โครงสร้างพิเศษ · D Smart Guard · Optimizer ราคาต่อตัว · VAT · เงินจอง

## การคำนวณ
| รายการ | ราคา |
|---|---|
| ระบบโซลาร์ | Price List ตามขนาด (kWp) และระบบไฟ (1/3 เฟส) |
| แบตเตอรี่ (Hybrid) | Price List ตามขนาด 7 / 14 / 21 kWh |
| Optimizer | จำนวนแผง × ราคาต่อตัว |
| Smart Guard | ตามระบบไฟ 1 / 3 เฟส |
| โครงสร้างพิเศษ | ตามขนาดระบบ (ลูกปูนบนดาดฟ้า) |
| มิเตอร์ TOU | ตามที่ตั้ง (0 = ฝ่ายขายกรอกเอง) |

ราคาก่อนส่วนลด = รวม Price List · ส่วนลดโปรโมชั่น = รวมส่วนลดในงาน (ฝ่ายขายแก้ได้) · ราคาสุทธิ → VAT 7% → รวมทั้งสิ้น
งวดชำระ: เงินจอง → 50% / 45% / 5% ของยอดคงเหลือหลังหักเงินจอง
ราคาสุทธิต่ำกว่า Minimum → เตือนฝ่ายขาย (ไม่แสดงในเอกสารที่ให้ลูกค้า)
