# ระบบโหวตการประกวดแบบ · Realtime

กรรมการให้คะแนนจากมือถือ แล้วคะแนนขึ้นบนจอใหญ่ทันที (หน่วงไม่ถึง 1 วินาที)
เป็น **ฟังก์ชันเสริมของเว็บภายใน Prime Power** (แถบ 🎉 ประกวดปีใหม่) และใช้ **Firebase Realtime Database** (แพ็กเกจฟรี Spark) เป็นตัวส่งข้อมูลสด

> **เปิด/ปิด** ที่เว็บภายใน → จัดการข้อมูล → 🧩 ฟังก์ชันเสริม · ปิดแล้วแถบหาย และเปิดลิงก์ในโฟลเดอร์นี้ตรง ๆ ก็เข้าไม่ได้
> ทุกหน้าต้องเปิดผ่านเว็บภายใน (ล็อกอินก่อน) — เว็บภายในส่งค่า Firebase และผู้ใช้ที่ล็อกอินมาให้ทาง localStorage `pp-contest`
>
> - **กรรมการ**: ผู้ดูแลผูกกรรมการกับรายชื่อบุคลากร (แท็บกรรมการ → ผูกบัญชี) → กรรมการเห็นการ์ดกรรมการในแถบประกวด ไม่ต้องเลือกชื่อ ใส่ PIN ครั้งแรกครั้งเดียวต่อเครื่อง
> - **โหวตขวัญใจ** (`vote.html`): พนักงานโหวตได้คนละ 1 สิทธิ์ ผูกกับบัญชีที่ล็อกอิน · ผู้ดูแลเปิด/ปิดโหวตที่แท็บควบคุม · แสดงผลบนจอด้วยโหมด "ผลโหวตขวัญใจ"
> - Firebase เก็บ **รหัสแทนอีเมล** (SHA-256) ไม่เก็บอีเมลจริง
> - ข้อจำกัด: สิทธิ์โหวตตรวจที่ฝั่งเบราว์เซอร์ (Firebase ไม่รู้จักบัญชี Microsoft ของบริษัท) คนที่ตั้งใจแก้โค้ดเองอาจโหวตแทนคนอื่นได้ เหมาะกับกิจกรรมสนุกภายใน ไม่ใช่การลงคะแนนที่ต้องตรวจสอบได้

| หน้า | ใช้ทำอะไร |
|---|---|
| `judge.html` | กรรมการ (แท็บเล็ต/มือถือ): เลือกชื่อ → PIN → เห็นรูปทีม + **แป้นตัวเลขแบบเครื่องคิดเลข** กดคะแนนทีละเกณฑ์ → ระบบรวม (sum) → **ยืนยันคะแนน** |
| `display.html` | จอแสดงผล: **แถบคะแนน** (รูปกรรมการ + คะแนนแต่ละคน + ค่าเฉลี่ย) แบบ realtime ทันทีที่กรรมการยืนยัน · ทีมปัจจุบันเต็มจอ · อันดับสด · ซ่อนคะแนน · ประกาศผล |
| `admin.html` | หลังบ้าน: ทีม (รูป รหัส ชื่อ), กรรมการ (รูป PIN), เกณฑ์, พื้นหลัง/โลโก้, ควบคุมทีมที่นำเสนอ, ล็อก, ลบคะแนนให้กดใหม่, CSV |

### คะแนน: เฉลี่ยเต็ม 10
- คะแนนกรรมการแต่ละคน = ผลรวมทุกเกณฑ์ เทียบเป็นเต็ม 10 (ถ้ามีเกณฑ์เดียวเต็ม 10 ก็คือเลขที่กดเลย)
- คะแนนทีม = ค่าเฉลี่ยของกรรมการทุกคน เช่น 7+8+5+10+10+6+7+8 = 61 ÷ 8 = **7.63**
- เปลี่ยนเป็นเต็ม 100 หรือคะแนนดิบได้ที่ ตั้งค่า → สเกลคะแนน

### พื้นหลังของแต่ละทีม (รูป / GIF / คลิปวนซ้ำ) — ไม่ต้องต่อกล้อง
- หลังบ้าน → **ทีมประกวด** → ปุ่ม 🎬 พื้นหลัง ของแต่ละทีม หรือ **พื้นหลังหลายไฟล์** (ตั้งชื่อไฟล์ตามรหัสทีม `A01.mp4`, `A02.gif`, `A03.jpg` ระบบจับคู่ให้)
- เมื่อผู้ดูแลกด "ทีมถัดไป" จอจะเปลี่ยนพื้นหลังเป็นของทีมนั้นแบบค่อย ๆ จาง (crossfade) และเล่นวนซ้ำ
- หน้าจอแสดงผลต้องตั้งเป็น **รูป/คลิปพื้นหลัง** · ทีมที่ไม่มีพื้นหลังจะใช้ **พื้นหลังหลัก**
- ไฟล์ละไม่เกิน 7 MB (เก็บในฐานข้อมูล) · คลิปใหญ่กว่านั้นให้ใส่ในโฟลเดอร์ `media/` ของเว็บแล้วใช้ปุ่ม 🔗 (ดู media/README.txt)
- คลิปเล่นแบบไม่มีเสียง (เบราว์เซอร์ไม่อนุญาตให้เล่นเสียงอัตโนมัติ) · ใช้ MP4 (H.264) หรือ WebM
- มือถือกรรมการไม่โหลดไฟล์พื้นหลังเหล่านี้ จึงไม่กินเน็ตกรรมการ

### เตรียมข้อมูลก่อนวันงาน
- **นำเข้าจาก Excel**: คัดลอก 3 คอลัมน์ (รหัส | ชื่อทีม | สมาชิก) วางได้ทีเดียวทุกทีม
- **รูปทีมหลายไฟล์ / พื้นหลังหลายไฟล์**: เลือกทั้งโฟลเดอร์ ระบบจับคู่ตามชื่อไฟล์และแจ้งไฟล์ที่ไม่ตรง
- แท็บ **ควบคุม** มีการ์ด **ความพร้อมก่อนเริ่มงาน** บอกว่าอะไรยังขาด (แตะเพื่อไปแก้)

### หลังจบการประกวด: หน้าสรุปผลทุกทีม
- หลังบ้าน → **หน้าสรุปผล**: ตั้งหัวข้อ ชื่อรางวัล (ชนะเลิศ/รองฯ) จำนวนทีมที่แสดง แสดงคะแนนกรรมการรายคน และอัปโหลด **พื้นหลังเฉพาะหน้าสรุปผล** (รูป/GIF/คลิป)
- กด **🏆 แสดงหน้าสรุปผลบนจอ** → แท่นรางวัล 3 อันดับ + รายชื่อทุกทีมเรียงคะแนน พร้อมพลุ
- หรือ **ประกาศทีละอันดับ** เพื่อลุ้นจากท้ายขึ้นไปอันดับ 1
- แท็บ **ผลคะแนน**: แตะช่องคะแนนเพื่อ **แก้ไข / กรอกแทน / ลบ** และดาวน์โหลด CSV

### พื้นหลังจอแสดงผล
- **พื้นเขียว / น้ำเงิน (Chroma key)** — ส่งเข้า vMix / OBS / ATEM แล้ว key สีออก เพื่อซ้อนแถบคะแนนบนภาพกล้องสด
- **โปร่งใส** — ใช้เป็น Browser Source ใน OBS ได้เลยไม่ต้อง key
- **รูปพื้นหลัง** — อัปโหลดรูป 1920×1080 สำหรับฉายโปรเจกเตอร์ตรง
- ลิงก์ `display.html?bg=green&view=lowerthird` บังคับพื้นเขียว + แถบคะแนน ใช้คู่กับจอโปรเจกเตอร์อีกจอได้พร้อมกัน

> ถ้ายังไม่ได้ใส่ค่า Firebase ระบบจะอยู่ใน **โหมดทดลอง** — ใช้ได้เฉพาะในเบราว์เซอร์เครื่องเดียว (เปิดหลายแท็บเพื่อลองได้)

## ขั้นที่ 1 — ตั้งค่า Firebase (ประมาณ 10 นาที)

1. ไปที่ https://console.firebase.google.com → **Create a project** (ปิด Google Analytics ได้)
2. **Build → Authentication → Get started → Sign-in method → Anonymous → Enable → Save**
3. **Build → Realtime Database → Create Database**
   - Location: **Singapore (asia-southeast1)** เพื่อให้หน่วงต่ำ
   - เลือก **Start in locked mode**
   - ไปที่แท็บ **Rules** → ลบของเดิม → วางเนื้อหาจากไฟล์ `database.rules.json` → **Publish**
4. **⚙ Project settings → General → Your apps → ไอคอน `</>` (Web)** → ตั้งชื่อ → Register
   คัดลอกก้อน `firebaseConfig` ไปวางที่เว็บภายใน (ขั้นที่ 2)
   (ต้องมีบรรทัด `databaseURL` ถ้าไม่มีให้คัดลอก URL จากหน้า Realtime Database มาใส่เอง)

## ขั้นที่ 2 — วางค่าในเว็บภายใน

1. เว็บภายใน → **จัดการข้อมูล → 🧩 ฟังก์ชันเสริม** → เปิดสวิตช์ระบบประกวด
2. วางก้อน `firebaseConfig` ในช่อง **ค่า Firebase** แล้วกด 💾 บันทึก (ไม่ต้องแก้ไฟล์ในโค้ด)
3. Firebase → **Authentication → Settings → Authorized domains → Add domain** → ใส่โดเมนของเว็บภายใน

## ขั้นที่ 3 — เตรียมงาน

1. เปิด `admin.html` → **ตั้งรหัสผู้ดูแลทันที** (ใครตั้งก่อนคนนั้นเป็นผู้ดูแล)
2. แท็บ **เกณฑ์คะแนน**: ใส่ชื่อเกณฑ์และคะแนนเต็มของแต่ละข้อ (คะแนนกรรมการ = ผลรวมทุกข้อ)
3. แท็บ **ทีมประกวด** และ **กรรมการ**: ใส่ชื่อ + อัปโหลดรูป (ระบบย่อรูปเอง) · ระบบสุ่ม PIN ให้กรรมการ → ปุ่ม "คัดลอกรายชื่อ + PIN" ส่งต่อใน LINE ได้
4. แท็บ **หน้าจอแสดงผล**: เลือกพื้นหลัง อัปโหลดรูปพื้นหลัง/โลโก้ ปรับตำแหน่งและขนาดแถบคะแนน
5. แท็บ **ตั้งค่า**: ชื่องาน/ชื่อรอบ, วิธีรวมคะแนน (เฉลี่ย/รวม/ตัดสูง-ต่ำ), ความละเอียดที่กดได้ (จำนวนเต็ม/0.5/ทศนิยม), แก้คะแนนหลังยืนยันได้หรือไม่, กรรมการตามทีมที่ผู้ดูแลเลือกหรือเลือกเอง
6. ซ้อมด้วย **ตั้งค่า → โหลดข้อมูลตัวอย่าง / สุ่มคะแนนทดสอบ** แล้วกด **ล้างคะแนนทั้งหมด** ก่อนเริ่มจริง

## ระหว่างงาน

- เปิด `display.html` บนโน้ตบุ๊กที่ต่อโปรเจกเตอร์ → กด **F** เพื่อเต็มจอ (เมาส์จะซ่อนเอง)
- ให้กรรมการสแกน QR ในหน้าแอดมิน
- **ควบคุม → สถานะ: เปิดให้คะแนน** แล้วกด **ทีมถัดไป ›** ทีละทีม — เครื่องกรรมการเปลี่ยนตามทันที
- โหมดจอที่แนะนำ:
  - **แถบคะแนน** ระหว่างนำเสนอ คะแนนกรรมการแต่ละคนเด้งขึ้นทันทีที่กดยืนยัน พร้อมค่าเฉลี่ย
  - **ซ่อนคะแนน** ถ้าอยากเก็บความลุ้นไว้จนจบ
  - **ประกาศผล** กด "เปิดเผยอันดับถัดไป" จากอันดับสุดท้ายไล่ขึ้นไปจนถึงอันดับ 1 (มีพลุ)
- **ล็อกคะแนน** เพื่อปิดรับทีมนั้น · กรรมการกดผิด → แท็บ **ผลคะแนน** แตะช่องคะแนนเพื่อลบ ให้กรรมการกดใหม่
- จบงาน: **ผลคะแนน → ดาวน์โหลด CSV** (เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน)

## หมายเหตุด้านความปลอดภัยและข้อจำกัด

- `apiKey` ของ Firebase เปิดเผยในโค้ดได้ตามปกติ ความปลอดภัยมาจากไฟล์ **Rules**
  - กรรมการเขียนคะแนนได้เฉพาะของตัวเอง เมื่อ PIN ถูก ระบบเปิดรับ และผลงานยังไม่ล็อก
  - ค่าคะแนนต้องอยู่ในช่วง 0 ถึงคะแนนเต็ม
  - PIN อ่านได้เฉพาะผู้ดูแล
- คะแนนดิบอ่านได้แบบสาธารณะ เพราะจอแสดงผลต้องใช้ ผู้ที่รู้วิธีเปิดดูข้อมูลจึงเห็นคะแนนได้แม้อยู่ในโหมด "ซ่อนคะแนน"
- แพ็กเกจฟรีรองรับ **การเชื่อมต่อพร้อมกัน 100 เครื่อง** ซึ่งพอสำหรับกรรมการ + จอ + แอดมิน
  ผู้ชมกว่าร้อยคนให้ดูผ่านจอใหญ่ ถ้าจะเปิดให้ผู้ชมดูบนมือถือของตัวเองด้วย ต้องอัปเกรดเป็นแพ็กเกจ Blaze (จ่ายตามใช้ ส่วนใหญ่แทบไม่เสียเงิน)
- ฟอนต์ Kanit และ IBM Plex Sans Thai รวมไว้ในโฟลเดอร์ `fonts/` แล้ว ไม่ต้องโหลดจาก Google Fonts

```
fonts/  vendor/qrcode.js
```

สูตรคะแนน: คะแนนกรรมการแต่ละคน = ผลรวมคะแนนทุกเกณฑ์
คะแนนของทีม = ค่าเฉลี่ยของกรรมการ (หรือเลือก รวมทุกคน / ตัดคะแนนสูงสุด-ต่ำสุดออกเมื่อมีกรรมการ ≥ 5 คน)

รูปภาพเก็บใน Realtime Database (ย่อเป็น JPEG ให้อัตโนมัติ) จึงไม่ต้องใช้ Firebase Storage ซึ่งต้องผูกบัตรเครดิต
ในโหมดทดลองเบราว์เซอร์เก็บได้ราว 5 MB — ถ้าอัปรูปเยอะให้ต่อ Firebase ก่อน
