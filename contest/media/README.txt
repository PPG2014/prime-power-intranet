⚠ repo นี้เป็นสาธารณะ ไฟล์ที่ใส่ในโฟลเดอร์นี้ทุกคนเปิดดูได้ — ใส่เฉพาะคลิป/รูปที่เผยแพร่ได้
   ไฟล์ส่วนตัวให้อัปโหลดที่ ควบคุมการประกวด → ทีมประกวด → 🎬 พื้นหลัง (เก็บใน Firebase)

โฟลเดอร์นี้สำหรับไฟล์พื้นหลังขนาดใหญ่ (คลิปเกิน 7 MB)
1) อัปโหลดไฟล์ไว้ในโฟลเดอร์นี้บน GitHub เช่น media/A01.mp4
2) หลังบ้าน → ทีมประกวด → ปุ่ม 🔗 ของทีม → พิมพ์ media/A01.mp4
แนะนำ MP4 (H.264) หรือ WebM ความละเอียด 1920x1080 ความยาว 5–20 วินาที (เล่นวนซ้ำ ไม่มีเสียง)
